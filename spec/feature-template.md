# Feature — 名称

状态流转 Draft → Accepted → Implementing → Implemented；未验证前不能标 Implemented。

## 背景与目标

说明用户场景、解决的问题和明确不包含的范围。

## 前置依赖与影响范围

列出关联 feature、模块、协议版本及跨仓库影响。

## 接口与数据

定义输入/输出、实体字段、身份/权限、版本、幂等、错误和兼容策略。

## 实现方案

描述模块职责、数据流、状态机、不变量和关键算法；区分已决定与待决定事项。

## 失败与恢复

覆盖超时、重复/乱序、取消、重启、部分成功及外部副作用未知等适用场景。

## 实施步骤

列出可以分阶段验证的交付项。

## 验收与验证

说明正常/异常场景、需要执行的检查及成功标准；不为纯文档改动编造测试。

## 迁移与发布

兼容、数据迁移、回滚及依赖版本变化；不适用时说明。
